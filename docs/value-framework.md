# 价值锚定框架 v3（用户校准 2026-10-31）

权威目标与软先验。系数可被时代 1 计分校准改写；**不是**锁死的静态真理。

## 1. 目标函数

- **只比分数（VP）**：分高者胜；尽量争第一，否则尽量抬自己的分。
- **破产**：规则内大额扣分 ≈ 退出竞争，与「比分」一致，不必另立否决目标。
- 启发式 / MCTS 叶子主轴 = **自己的期望终局（本阶段：时代 1 计分）VP**。

## 2. 钱 ↔ 分

- 粗锚：**约 2 块 ≈ 1 分**；**早期钱贵、后期分贵**。
- 细比例交给搜索 / 时代 1 定锚发掘；代码里只用随回合缓降的软曲线（见 `src/ai/valueUnits.ts`）。
- 旧四段表（0.65/0.50/…）与扁平 `Δmoney×0.35` **不当真理**。

## 3. 收入

- **规则上收入不算分**。
- `K≈0.55` 仅为早期口头倒推，**可作贪心软先验，不当最终真理**。
- 上 MCTS / 推到时代 1 计分的目的之一：发现「抬收入」相对「直接拿分」何时值。
- 叶子评估**不得**把收入 level 伪造成 VP 大头；最多作「未来钱期权」轻量项。

## 4. 高级产业

- 核心瓶颈：**把「钱 + 行动」高效转化成 VP**。
- 高级 / 皇冠单动常十余 VP，低级约 5；只造低级 → 钱多换不出分。
- 评估应偏好**可兑现的高档产业分**，不是堆低级产能件数。
- 流派目标线（如 122 箱 / 223 油）是参考不是铁律；研掉 1 箱、改焦铁等都可以，只要分够。

## 5. 开局软先验（审计标准，非 if 森林）

默认：**煤开 > 贷开 > 管开**；有牌时**巴里/克堡煤开**优先于萨吉诺等西北空降。

**为何先验而不是让浅层 MCTS「自己证明」：**  
先手第一座建筑是路网空降，前两回合合法动作爆炸；时代 1 早期真实目标之一是**翻正首贷收入**，翻煤是最稳手段之一。线下大量对局里先手巴里煤开是稳定优解。浅层 MCTS（短 rollout）在巨分支下很难「从零发现」这条链——搜不到 ≠ 不是好动。先验用来压分支、对齐人类经验；若将来推到时代 1 计分的深搜稳定推翻它，可以改先验，而不是现在就删掉。

无巴里/克堡/煤牌才考虑克堡或巴里管开；托莱多管开 / 空降托莱多通常不可取（例外：双修路开托莱多→芝加哥/萨吉诺补煤）。

资源经济：

- 免费资源价值 = 市场最低补价（煤铁 2、钢焦 4）；补市场另加翻面加速。
- 外部买：R1-4 无额外收益不可接受，R5 起放宽。
- 首贷几乎常做；场上有己煤、能连铁/压收入时抬贷价值；满补 2 煤 / 满补 1 铁可作贷价值量级锚。

控顺位 / 沉底末动：触发深层连续估值（贷轻铁焦等）——交给加深搜索，不手写整条专家链。

## 6. 硬红线（仅此）

- **断管 = 储备管道**。当自己可用区里**还能铺**收入管 / 钱管 / 分管时，**不要优先选储备管道**（只在没有更好管型可铺、或确有占油田必要时才用）。
- 外部买资源、贷款：**不是硬红线**，纯价值判断。

## 7. 定锚视野

- 不追求整局 15 回合全树（组合爆炸）。
- **时代 1 动作锚 = 时代 1 计分后自己的 VP（相对最高对手）**；收入不与分并列。
- 实现：`src/ai/era1Anchor.ts`（`era1AnchorChoose` / `playToEra1Held`）。根上用 `proposeRootActions` 取前若干招，各推到一时代计分再比 VP。
- **时代 2 / 终局锚**（下一阶段）：`src/ai/finalAnchor.ts`（`finalAnchorChoose` / `playToGameOver`）。根招各贪心推到 `over`，用终局相对 VP 选招。热座「定锚」脑在时代 2 自动切到此路径。
- 生产热座默认仍贪心 / 浅 MCTS；定锚算力贵，作离线探针与日后校准，**不要**为单个臭招给 `scoreAction` 打补丁（易价值紊乱 / 过拟合）。
- 尚未做：用终局锚系统回写时代 2 `scoreEra2` / `evaluateState`（与时代 1 校准同套路，另开一轮）。

### 定锚对照（8 种子子集，2026-10-31）

- R1 首招：定锚略增核心煤（6 vs 5）；制造业开仍有。
- `pickLoanAction` 强制并进定锚根集；`playToEra1Held` 对决策者默认 `loanAware`（负收入优先核心煤，早期可主动首贷）。
- **顺位代理** `seatTempoProxyVp`：花费少 / 投影下回合靠前加分（贷款$0 vs 造厂花钱）；早期贷且贷后仍能核心煤再 +5 经典贷开信用。
- **经典贷开审计**（巴里已有煤且己方仍能造核心煤）：可贷 8/8；贷开贪心 **0** / 定锚 **3**（加席位代理后；先前 loanAware  alone 为 2）。仍有一半局面定锚偏好直接煤——接受为 VP+席位与人类「抢顺位」不完全同构。
- **外部焦/钢审计**（8 种子中首遇外部买焦/钢的建造）：命中 6；定锚避开 **4/6**、仍外部 2/6——时代分能压多数臭招，无需单点补丁。
- 热座可选脑：`贪心` → `MCTS` → `定锚(慢)`（顶栏循环；时代1=计分锚，时代2=终局锚；每步可数十秒～更久）。
