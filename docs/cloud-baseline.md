# Brass · 云端门禁基线（2026-10-31 修正）

> **取代**旧方案中「生产默认 MCTS 16×2 + seed777 必须巴里」的表述。  
> 本文件只定义**保护什么**；改 AI 算法仍走价值计划，不在云基建任务里改决策逻辑。

---

## 1. 生产默认决策（热座）

| 项 | 基线 |
|---|---|
| 默认脑 | **贪心** `chooseAiAction` |
| 可选 | MCTS / 时代1定锚（UI 顶栏循环；定锚极慢） |
| 不得 | 把云门禁写成「必须默认 MCTS」 |

## 2. MCTS 参考参数（可选脑，非默认）

若跑 MCTS 回归，使用生产可选参数（勿擅自改门禁期望）：

- `iterations: 16`
- `rolloutDepth: 2`
- `topK: 4`
- `topM: 8`

## 3. seed777 开局

| 项 | 基线 |
|---|---|
| 行动者 | `currentPlayerId === 3`（P4） |
| 期望 | **核心城煤开**：`wilkes-barre` **或** `clarksburg` |
| 不得 | 强制「只能巴里」 |
| 断管 | 可用区还有非储备管时，不优先选 `pipelineType === 'reserve'` |

## 4. 破产回归

| 套件 | 期望 |
|---|---|
| `src/era1diag.test.ts`（20 种子） | 破产 **≤ 1/80**（近期实测 **0/80**） |
| 决策器 | 套件内为 **贪心** `chooseAiAction` |

## 5. 观测项（报告用，不作硬失败门禁）

- 开局桶：核心煤 / 造箱 / 管 / 贷（`npm run era1:baseline`）
- 外部焦/钢：定锚避开率（`npm run era1:outside`，慢）
- 经典贷开：巴里有煤且仍能核心煤时定锚贷开次数（`npm run era1:compare`，慢）

## 6. 硬红线（规则/价值文档）

- 断管 = **储备管道**；有更好管型可选时不优先储备管。
- 不为「外部焦炭造钢」等单点加 `scoreAction` 特判（用时代分定锚压）。

## 7. 变更策略

云基建 PR：**只加环境与测试壳**，不改 `choose.ts` / `era1Anchor.ts` 决策逻辑。  
算法变更另开 PR，并同步更新本基线文档中的期望数字。
